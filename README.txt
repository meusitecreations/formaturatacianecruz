CONVITE DIGITAL — TACIANE BAUM CRUZ

ARQUIVOS
- index.html: convite principal.
- presente.html: página com a chave PIX.
- assets/foto-1.jpg: fotografia original fornecida.
- assets/flores-aquarela.png: composição floral original fornecida.
- assets/style.css: estilos e identidade visual.
- assets/script.js: animações, formulário e cópia do PIX.

COMO VISUALIZAR
Abra index.html no navegador. Para testar o envio do formulário, publique o site em uma hospedagem estática com HTTPS (por exemplo, GitHub Pages).

PUBLICAÇÃO NO GITHUB PAGES
1. Entre no GitHub e crie um repositório público chamado convite-formatura (ou outro nome).
2. Envie todos os arquivos e pastas deste ZIP, mantendo a estrutura.
3. No repositório, abra Settings > Pages.
4. Em Build and deployment, selecione Deploy from a branch.
5. Escolha a branch main e a pasta / (root), depois salve.
6. Aguarde a publicação e acesse o endereço informado pelo GitHub Pages.

FORMULÁRIO DE CONFIRMAÇÃO
O formulário utiliza FormSubmit, com envio AJAX para tacianecruzbm@gmail.com.
Na primeira utilização, o FormSubmit pode enviar uma mensagem de ativação para esse endereço. A ativação é feita pelo titular do e-mail, uma única vez. A página pública não exibe instruções técnicas.
Faça um teste real após a publicação e verifique a caixa de entrada e a pasta de spam.

PERSONALIZAÇÃO
Os dados principais estão no HTML:
- index.html: nome, curso, instituição, data, horários, locais, prazo e e-mail do formulário.
- presente.html: texto e chave PIX.
- assets/style.css: cores e fontes no início do arquivo (:root).
Se alterar o e-mail do formulário, altere também o endereço na URL fetch de assets/script.js.
